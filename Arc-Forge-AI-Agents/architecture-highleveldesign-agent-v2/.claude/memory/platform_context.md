**TALON Rev** and **Phoenix** refer to the same platform — the new system being built.

**TALONes** is the old/legacy application that is being re-engineered into Phoenix/TALON Rev.

**Why:** The team uses both names interchangeably in conversations, JIRA tickets, and Confluence pages. Agents must recognise Phoenix = TALON Rev at all times to avoid confusion when users switch between terms.

**How to apply:** Whenever a user or document mentions "Phoenix", treat it as "TALON Rev". When they mention "TALONes", understand they are referring to the legacy system and consider migration concerns (data migration, parity gaps, TALONes-specific business rules) as relevant context.

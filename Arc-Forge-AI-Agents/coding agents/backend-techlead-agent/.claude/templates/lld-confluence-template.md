# LLD Confluence Page Template

## Purpose
This template defines the exact structure of every LLD page published to Confluence by the `confluence-publisher-agent`. The publisher builds the page HTML from this template, substituting generated content into each section.

**Page title:** `<hld_core_name> - LLD`

Where `<hld_core_name>` is the HLD page title with any leading/trailing 'HLD' text stripped. Example: HLD titled `"Service - Manage Stock Items HLD"` → LLD title is `"Service - Manage Stock Items - LLD"`.
**Parent page:** The HLD page for this epic (child page of HLD)
**Labels:** `lld`, `auto-generated`, `dotnet`, `<jira-project-key>`

---

## Page Structure

```
<hld_core_name> - LLD
├── [Auto-generated notice panel]
├── [Table of Contents]
├── 1. Overview
├── 2. Scope
│   ├── 2.1 User Stories Covered
│   └── 2.2 Out of Scope
├── 3. Affected Services
├── 4. Component Diagram
├── 5. Database Design
│   └── 5.x <ServiceName> — DB Changes (one per service)
├── 6. API Changes
│   └── 6.x <ServiceName> — API Changes (one per service)
├── 7. Event Changes
│   └── 7.x <ServiceName> — Event Changes (one per service)
├── 8. Cross-Service Flows
├── 9. Traceability Matrix
├── 10. Assumptions & Gaps
└── 11. Review Notes
```

> **JSON schema format guidance:**  
> Write schemas as a JSON object where each key is a field name and the value is an object describing `type`, `required` (boolean), `nullable` (boolean), `description`, and any constraints (`minLength`, `maxLength`, `minimum`, `maximum`, `enum`, `default`). For arrays, include an `items` key. For nested objects, inline the child schema. Example structure:
> ```json
> {
>   "fieldName": {
>     "type": "string | integer | number | boolean | array | object",
>     "required": true,
>     "nullable": false,
>     "description": "...",
>     "maxLength": 100
>   }
> }
> ```
>
> **JSON example format guidance:**  
> Write examples as a realistic JSON payload a developer would send or receive. Use plausible values (real-looking IDs, meaningful strings, non-zero quantities). Do not use `"string"` or `0` as placeholder values.
